# Public release scope — v0.3.0-alpha.9

This is the clean public reproducibility package for the manuscript “Control-aware training of physical neural networks for homeostatic regulation”.

Included: project-maintained scientific source code, frozen confirmatory assets required for reproduction, confirmatory result tables, source data underlying the manuscript, public provenance records, tests, and A-060 statistical reporting sensitivity analysis.

Excluded: internal research notes, exploratory review discussions, submission-only Nature template files, A-061/A-062 submission-governance audits, development clutter not required for reproduction, and third-party binary experimental source files. External experimental measurements are represented only through project-authored factual extraction/provenance tables where redistribution rights are clear.


Archival metadata for the planned stable GitHub/Zenodo `v1.0.0` release is included under `release_metadata/`.
