# External data provenance registry — v0.3.0-alpha.8

No third-party research source code or third-party binary experimental dataset is bundled in this software package.

E-040 uses a **project-authored factual extraction table** transcribing numerical experimental values explicitly reported in cited publications. The associated project-level provenance record documents DOI/source locations and the distinction between repository code licensing and measurement-data reuse. Third-party `.xlsx`, notebooks and checkpoints inspected during due diligence are not redistributed.

Any future external dataset inclusion requires a separate provenance entry recording DOI/repository, exact file identity, reuse/license basis, retrieval date and SHA-256.
