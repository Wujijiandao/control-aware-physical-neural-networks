# Source data — v0.3.0-alpha.8

This directory contains project-generated source data supporting the current manuscript figures and confirmatory numerical claims.

- `Fig1_E010C1_raw_per_seed.csv`: E-010C1 paired confirmatory episodes.
- `E020C1_primary_paired.csv`: E-020C1 frozen primary paired endpoint.
- `E020C1_all_raw_per_seed_condition.csv`: E-020C1 frozen secondary robustness conditions.
- `Fig2_E020C1_condition_summary.csv`: condition-level summary for the interferometric robustness figure.
- `Fig3_E030C1_raw_per_seed.csv`: E-030C1 oscillator matched-static confirmatory episodes.
- `E030C1_paired.csv`: paired E-030C1 endpoint data. E-030C1 is retained despite failing its frozen 5% minimum-effect threshold.
- `Fig4_E031C1_primary_raw.csv`: E-031C1 oscillator robustness primary raw data.
- `E031C1_primary_paired.csv`: paired E-031C1 primary endpoint data.
- `E050C1_primary_paired.csv`: E-050C1 per-seed task-matched primary endpoint.
- `Fig5_E050C1_condition_taskmatched.csv`: condition-level task-matched data underlying the Pareto audit.
- `E050C1_raw_taskweight_grid.csv`: full frozen task-weight grid used for interpolation.
- `E051C1_primary_paired.csv`: substrate-specific paired decision-regret co-primary data.
- `Fig6_E051C1_gap_regret_summary.csv`: common-state action-gap quartile summaries.
- `E051C1_raw_common_state.csv`: per-seed/method/condition decision-regret summaries.
- `Table1_E040_external_measurement_anchors.csv`: project-authored factual extraction underlying the external stress-envelope table; values are explicitly reported in cited experimental articles.
- `E040_external_anchor_metrics.csv`: project-derived chance-adjusted and retention metrics from the E-040 audit.

Third-party research code and third-party binary experimental data are not redistributed here.
