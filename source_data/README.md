# Source data — v0.3.0-alpha.10

This directory contains project-generated source data supporting the current manuscript figures, table and confirmatory numerical claims.

- `Fig1_E010C1_raw_per_seed.csv`: E-010C1 paired confirmatory episodes.
- `E020C1_primary_paired.csv`, `E020C1_all_raw_per_seed_condition.csv`, `Fig2_E020C1_condition_summary.csv`: E-020C1 robustness source data.
- `Fig3_E030C1_raw_per_seed.csv`, `E030C1_paired.csv`: E-030C1 oscillator matched-static data; threshold failure retained.
- `Fig4_E031C1_primary_raw.csv`, `E031C1_primary_paired.csv`: E-031C1 oscillator robustness data.
- `E050C1_primary_paired.csv`, `Fig5_E050C1_condition_taskmatched.csv`, `E050C1_raw_taskweight_grid.csv`: E-050C1 task-matched Pareto data.
- `E051C1_primary_paired.csv`, `Fig6_E051C1_gap_regret_summary.csv`, `E051C1_raw_common_state.csv`: E-051C1 decision-regret mechanism data.
- `E060_primary_paired.csv`, `Fig7_E060_cartpole_summary.csv`, `E060_secondary_bootstrap.json`: E-060C1 canonical Cart-Pole task-generalization data.
- `Table1_E040_external_measurement_anchors.csv`, `E040_external_anchor_metrics.csv`: project-authored external stress-envelope audit data.
- `A060_confirmatory_sign_test_sensitivity.csv`: post hoc exact two-sided paired sign-test / Holm reporting sensitivity for the eight headline paired contrasts. These P values do not replace the original project-frozen CI + minimum-effect classifications.

Third-party research source code and third-party binary experimental files are not redistributed here.
